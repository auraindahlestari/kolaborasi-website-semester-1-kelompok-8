Jam & Lampu Unik

Lihat Detail

Penyelesaian SPLDV

Paket A

1 Lampu + 1 Jam = Rp 145.000

Paket B

2 Lampu + 1 Jam = Rp 205.000

Misal:

  • x = harga 1 Lampu
  • y = harga 1 Jam Harddisk

Model: x+y=145rb | 2x+y=205rb

1. Eliminasi Variabel y

(2x + y) - (x + y) = 205.000 - 145.000

x = 60.000

Harga 1 Lampu = Rp 60.000

2. Substitusi x

60.000 + y = 145.000

y = 85.000

Harga 1 Jam = Rp 85.000

Cek Hasil

Paket A: 60rb + 85rb = 145rb ✅

Paket B: 2(60rb) + 85rb = 205rb ✅

Kesimpulan

  • Lampu = Rp 60.000
  • Jam = Rp 85.000

Paket A

Paket B

Paket B: 2(80rb) + 120rb = 280rb ✅
